# 课程总览

> 这里整理了面向本科教学与延伸阅读的课程页面。每门课程都尽量把讲义脉络、主题范围和可下载资料放在一起，方便学生按课堂节奏学习。

## 本科基础课

### [大学物理](/courses/general-physics)

面向本科生的综合物理课程，覆盖从经典力学到近代物理的核心知识结构。

**主题**

- 力学
- 光学
- 热学
- 电磁学
- 相对论导论

## 理论工具

### [群论](/courses/group-theory)

从群的基本概念出发，逐步进入表示论、李群李代数，以及它们在物理中的典型应用。

**主题**

- 群表示论
- 李群
- 李代数
- 量子力学应用

## 交叉主题

### [物理与 AI](/courses/physics-ai)

记录一些关于 AI 与物理学习、研究、编程之间关系的思考，适合作为延伸阅读入口。

**主题**

- 学习方法
- 编程
- 交叉讨论

## 如何使用

1. 先进入课程页了解本课程覆盖的主题。
2. 按章节阅读讲义或查看侧边栏目录。
3. 需要 PDF、PPT 等文件时，前往 [资料下载](/resources)。
